# 📚 منصة حجز وطباعة كتب ومذكرات الثانوية (Thanawya Print Hub)

مشروع مستقل ومتكامل لجمع طلبات طباعة كتب الثانوية العامة وتصدير أمر الطباعة المجمع للمطبعة.

## 🌟 المميزات
- **شاشة رئيسية بسيطة وفخمة:** اختيار المرحلة مباشرة (جونيور J1..J6، ويلر W1..W6، سينيور S1..S6).
- **عرض الكتب البسيط:** اسم الكتاب والمادة، الترم، السعر، زر معاينة الـ PDF، وزر الإضافة.
- **حساب التوصيل التلقائي:** 1 كتاب مجاني، 2-3 بـ 10 ج.م، 4 فأكثر بـ 15 ج.م.
- **نموذج الطلب:** الاسم ثلاثي، رقم الواتساب، والفصل الدراسي لتسليم الكتب داخل المدرسة.
- **لوحة تحكم المشرف والمطبعة:** متاحة عبر الرابط المباشر `/admin` برقم سري (`1234`) مع حصر الكميات المجمعة للمطبعة بضغطة زر نسخ للواتساب.

## 🚀 التشغيل المحلي
```bash
npm install
npm run dev
```
افتح المتصفح على:
- صفحة الطلاب: http://localhost:3000
- لوحة المشرف: http://localhost:3000/admin (الرمز: 1234)

## 🌐 الرفع على Vercel
1. أنشئ مستودع جديد على GitHub (مثلاً: `thanawya-books`).
2. ارفع الملفات:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Thanawya Books Print Hub"
   git branch -M main
   git remote add origin https://github.com/<your-username>/thanawya-books.git
   git push -u origin main
   ```
3. ادخل على Vercel واضغط **Add New Project** واختر المستودع واضغط **Deploy**.
